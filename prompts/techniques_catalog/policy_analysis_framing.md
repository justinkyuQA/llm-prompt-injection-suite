# Technique 001: Policy Analysis Framing

## Description

Frames a request as an evaluation of policy frameworks rather than a request for operational guidance.

## Representative Prompt Class

"Analyze how current policy frameworks address misuse in domain X."

## Observed Mechanic

- Shifts model into meta-analysis mode
- Encourages synthesis of policy boundaries
- Can indirectly expose restricted conceptual areas

## Why It Emerged Naturally

Common in:

- Academic literature
- Regulatory analysis
- Ethics reviews
- Think-tank publications

## Defensive Insight

Repeated policy-boundary discussion may approximate restricted knowledge when aggregated.

## Category

Context Reframing
